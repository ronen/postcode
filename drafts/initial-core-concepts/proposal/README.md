# Initial core-concepts proposal

Status: in review

This is a non-governing planning package. It proposes the initial population of the core-concepts document and the corresponding bundled decision; it does not accept either or authorize implementation.

- [Complete proposed core-concepts document](docs/core-concepts.md) → `docs/core-concepts.md`.
- [Bundled proposed decision](decisions/initial-core-concepts-decisions.md) → `docs/decisions/initial-core-concepts-decisions.md`.

The core document contains the proposed current definitions. The decision contains their source basis, rationale, alternatives, consequences, and [unresolved ambiguities](decisions/initial-core-concepts-decisions.md#ambiguities-retained-for-review). Its source hierarchy treats the adopted design and accepted decisions as authority, the approved plan as corroboration, and current architecture and implementation as descriptive support.

The main review question is whether this vocabulary is sufficient and restrained. Property receives only a descriptive meaning; recorded-assertion taxonomy, general relationship structure, and logical versus materialized projection identity remain explicitly unsettled. Subject, View, and Analysis snapshot are included because they are needed to explain the requested concepts. Workspace/session models, storage APIs, state enums, and language-specific inventories are outside the proposed glossary.

Links resolve from this draft location. Promotion, if later directed by the human, requires rewriting links to canonical destinations and updating the canonical decision index together with the accepted document and decision. No canonical documents were changed to prepare this package.
