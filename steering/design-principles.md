# Design principles

These principles describe current design preferences and the reasoning behind them. They guide planning and may be reconsidered as the project gains experience.

<a id="named-investigations"></a>
## Prefer a small, familiar set of named investigations

Avoid free-prose questions. Frame architectural questions through named investigations such as `entity-overview`. Each investigation establishes what question it addresses and broadly what kind of account it should produce. Those expectations help designers judge whether a result answers the question and anticipate how it fits into the book’s organization and the reader’s path through it.

Some named investigations allow flexibility in their subject. For example, `explain` takes selected content as its subject. The content grounds the inquiry, while the investigation name sets an expectation for the kind of account it will produce.

Whether this repertoire can provide the architectural understanding readers need remains an open question.

See the [capability reference](../docs/capability-reference.md#interpretive-investigation) for supported investigations and [proposed investigations](../notes/proposed-investigations.md) for planning ideas.
