@investigram-98b5d92e · interpretation
`catalog` exposes `lookup`, coordinating keyed retrieval rather than implementing storage or remote access itself. It rejects an empty key; on a cache hit it returns the stored value; on a miss it awaits `readRemote`, stores the returned value with `remember`, then returns it. Because storage occurs only after the awaited read completes, a rejected remote request is not cached. The nearby README describes the same sequence.
