## Behavioral coverage

- Multiple tool exchanges follow entry → middle → leaf delegation through
  mechanically qualified dependency claims. Exports, symbol documentation,
  dependents, organization membership and opaque documentation artifact access
  use ordinary evaluators. Source supplied to the investigator exceeds human
  excerpt limits and carries captured full-file coverage.
- Multiple source mappings, explicit unavailable content, arbitrary-path and
  unsupported-tool rejection, excluded direct/alias content, immutable captured
  text after edits, input invalidation and forged mapping rejection exercise
  the shared acquisition boundary.
- Whole-result acceptance creates a multi-level immutable composition tree,
  distinct replacement trees, recursively accompanying corrections, competing
  alternatives, qualified associations and unresolved inconsistencies. It does
  not publish interpretation records. Missing qualifications, duplicate IDs,
  cycles, unsupplied evidence, non-prior targets and investigator-assigned
  mechanical status reject the entire submission.
- Exact originals, correction chains and competing replacements are supplied
  with explicit context. Bare identifiers do not create citations; excerpts do
  but cannot establish complete target eligibility. Separate exchanges can
  accumulate full target content. Bounded delivery exposes omitted references;
  complete correction context is recorded per correction without requiring
  subordinate composition trees.
- Failure outcomes distinguish missing submission, refusal, truncation,
  malformed results, communication/service failures and configuration
  unavailability. Acquired evidence and previously received synthetic usage
  survive failed attempts. Repeated domain executions open fresh dialogues;
  session outcome selection/retention is a later milestone.
- Time, agent-call, tool-call and volume guards cover provider and asynchronous
  evidence work. Interruption/invalidation reject late submissions, close the
  dialogue once and report prior usage with missing calls explicit. Unexpected
  defects remain thrown defects. Timely submission proceeds to ordinary
  validation rather than being retroactively stopped by a generation deadline.
- Usage category subset relationships remain explicit; identical repeated
  reports do not double count, conflicting reports are rejected and absent
  reports remain unknown. All test reports are marked synthetic.

## Reproduction and limits

Run `npm run check` and `npm test` from the repository root. The focused domain
suite is `npm run build && node --test _build/test/investigation.test.js`.
The final evidence regression check additionally includes
`_build/test/expansions.test.js`.

These checks establish domain mechanics, not live provider behavior or
interpretive usefulness. There is no inference credential setup, hosted adapter,
CLI investigation command, interpretation retention, session usage presentation,
reconsideration derivation or formative assessment at milestone 1. The
[architecture account](../../../docs/architecture/investigation.md) documents
the execution bounds, synchronous cancellation delay, full-file acquisition,
single-submit protocol and lack of repair/truncation recovery. Later milestones
remain subject to the approved review gates.
