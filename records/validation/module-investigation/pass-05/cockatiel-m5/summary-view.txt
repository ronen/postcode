@investigram-f0c3a29d · interpretation
ExecuteWrapper.invoke awaits the supplied function. An unfiltered resolved value becomes {success}; a result matching resultFilter becomes handled failure {value}; a thrown value matching errorFilter becomes {error}; and an unhandled throw is rethrown immediately. Success and failure events carry elapsed duration, while failures additionally report handled status and the error/value reason.

  Qualification: Both synchronous throws and asynchronous rejection enter the same catch because invocation is awaited inside try/catch.
