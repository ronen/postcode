# Milestone 5 integrated pass: frozen protocol

Authorized by the approved plan, milestone-5 instruction recorded in `1d74cb4`,
and the human's controlled-case refinement recorded in `bd00b66`. All sources,
reference material, setup recipes, general instructions and implementation hashes
are frozen before live inference. Expected answers and selection rationale are
never supplied to the investigator. The human-selected gpt-5.6-sol / medium /
ChatGPT-plan configuration and TypeScript 6.0.3 remain fixed, including the exact
merge-anything deprecation override. No model/route fallback or spending changes.

Run one fresh shell for each pinned upstream subject: summary, explanation,
decomposition and examination, including a follow-up on a generated result.
Choose targets from displayed views to serve these objectives and record the
choice/rationale separately. Inspect historical composition/provenance and
revisions, repeat a retained lens and summary, inspect source support, then usage.
Compare each summary and full sequence to milestone 3 with evidence, prompt,
transport and presentation changes explicit; this does not isolate model improvement.

Run a fresh refined numeric shell. Its frozen setup has three scripted evaluations:
functionality A, clarification Y of A, and decomposition Z of Y. A acquires the
small source through the normal tool before asserting a plausible mistaken account.
Y and Z preserve their warranted prior-interpretation qualification and exposure.
Then live examination of A, live clarification of Z, and live examination of Y.
Inspect A/Y/Z and any replacements after examination; repeat summary and a prior
follow-up. Record correction presence/absence and direct/transitive warnings at
each boundary. Do not add attempts merely because correction did not occur.
Documentation describes the interface without stating the conclusion under test;
no unverified qualifier is added to invite correction. Truthful scripted origin
remains visible. This reduces answer cues but does not measure unbiased spontaneous
error detection. Preserve the milestone-4 fixture and every historical result.

Run a separate fresh conflict shell on that same frozen source. Scripted A/Y/Z
are followed by examination of A producing replacement B and decomposition of A
producing competing replacement C. These are attributed test-origin alternatives,
not natural investigator contradictions. Then live examination of Z and live
clarification of B. Inspect A/B/C/Y/Z and any new replacements, record conflict
and reconsideration pages, repeat summary/follow-up and usage. This exercises
known conflict and warning context; semantic reconciliation is not claimed and
there is no automatic conflict-clearing operation. All scripted setup precedes
live work. No fixture or setup tuning is permitted within the pass.

For every upstream summary and integrated sequence, use a fresh view-only
comprehension evaluator, then a separate fresh source-informed assessor with the
frozen subject reference, exact views, evaluator response and rubric. Evaluate each
controlled case's full sequence with the same separation. Retain exact role
prompts, supplied inputs, outputs and available configuration. Roles may not read
additional repository files, plans, conversation history or web sources. Shared
model family/authorship/orchestration and unknown exact assistant identifiers
limit independence. Role usage and money remain separately unknown unless reported.

Use production per-evaluation guards: 180 seconds, 32 exchanges, 96 tools,
2,000,000 canonical-domain serialized UTF-16 code units before handle translation.
Seventeen scheduled live evaluations plus at most one communication recovery per
shell yield a 704-request administrative ceiling (22 times 32), not a usage target
or spending allowance. Planned assessments are separate from diagnostics; the
latter remain two used/eight available at freeze. No new diagnostic is planned.

At most one same-shell repeat of an affected request per shell is permitted only
for an evidenced plausibly transient communication failure. Preserve the failed
attempt. No repeat for refusal, truncation, invalid submission or guard stop.
Authentication/configuration/structural failures, quota/spending exhaustion and
unclassified errors stop for diagnosis or human direction. Interactive reauthorization
pauses for the human. An administrative ceiling is a reporting pause, not milestone
failure. There is no automatic retry or silent billing fallback.
