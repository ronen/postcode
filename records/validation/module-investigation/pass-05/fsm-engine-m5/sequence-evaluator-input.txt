@investigram-a86b8e57 · interpretation
`dispatch` is best understood as a synchronous queue drain, not as a direct recursive event handler. Every call first appends `{event, payload}` to the instance’s FIFO queue. If no drain is active, that call becomes the outer drain and processes queued items one at a time before returning. If the current processing throws before that queued event is reached, the queue is cleared instead.
