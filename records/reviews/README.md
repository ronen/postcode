# Review Records

This directory preserves durable independent-review handoffs, returned findings, and dispositions. Follow the [independent review workflow](../../dev/review.md) when a plan or task requires an independent review checkpoint.

Group new review series under a directory named for the governing plan, or for the task when no approved plan governs the work. A series may contain several review assignments, each beginning with a uniquely named `-handoff.md` file. Repeated findings and correction rounds may remain under one handoff while its assignment remains applicable. Use filenames ending in `-handoff.md`, `-findings.md`, or `-disposition.md` so each record's role is visible in a directory listing.

Use and adapt the development workflow's [review record templates](../../dev/templates/) for new records.

Existing records at this directory's root predate that organization. Preserve their names and links as historical evidence.
